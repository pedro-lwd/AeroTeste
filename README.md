Projeto para fazer uma analise de sensores de testes aerodinamicos simples,
foi feito um pequeno dataset artificial,como pressão no automóvel, a força descendente (downforce) e a velocidade do ar. o nivel do projeto é de um iniciante mas pode ser futuramente adaptado em uma versão
bem mais direta e funcional.

Antes de rodar a main.py para realizar a visualização do gráfico, gerar um dataset no arquivo dataset_generator.py.

O projeto consiste em trabalhar para resolver questões como análise de dados de médias e desvios de relações fundamentais da aerodinamica de um veiculo a pressão, força descendente e a velocidade do ar.

Os dados são processados em um pipeline totalmente feito em python com os pacotes: Pandas, MatPlotLib e Numpy, a escolha dos fatores utilizados (Linguagem e pacotes) foi por conta de uma facilidade pessoal, e a possibilidade de tornar os algoritmos adaptados à um nível avançado.

O projeto tem o intuíto pessoal de se distânciar do CRUD básico no python ja que eu não tenho paciência pra isso
fui direto para um projeto de engenharia que pra me desafiar, nesse projeto eu tive apoio guiado de documentações de projeto anteriores a esse e de inteligencias artificiais.
